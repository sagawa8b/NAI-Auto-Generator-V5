# 그림체 아레나

작가 태그를 무작위로 조합해 **그림을 실제로 뽑고**, 그 그림을 둘씩 놓고 골라(이상형 월드컵)
취향을 점수로 남기고, 이긴 조합끼리 **교배**해 더 마음에 드는 그림체를 찾아 가는 기능입니다.
감으로 작가를 섞어 보는 대신 **기록으로 남는 순위표**를 만듭니다.

> 전체 사용 설명서는 [MANUAL_KR.md](../MANUAL_KR.md)에 있습니다. 이 문서는 그중
> 그림체 아레나만 따로 뗀 것입니다 — 절이 길어 매뉴얼 안에서 찾기 어려웠습니다.

도구 → `그림체 아레나...`로 엽니다. 창은 모드리스라 메인 창을 막지 않습니다.

> 이 기능의 아이디어는 숭이717 님의
> [NAI 그림체 이상형 월드컵](https://arca.live/b/aiart/181388564)에서 왔습니다
> (원저자 허락을 받아 이식). 점수 매기는 방식 등 몇 곳은 다르게 잡았습니다.

## 흐름

```
작가 명단 → 무작위 조합 생성 → 그림 생성 → 이상형 월드컵 → 상위 조합 교배 → 반복
                                   ↑                                    │
                                   └────────────────────────────────────┘
                                     자식 조합도 그림을 뽑아 다시 겨룹니다
```

다섯 개 탭이 이 순서를 그대로 따릅니다. 앞 단계의 결과가 다음 단계의 재료가 되므로,
처음에는 왼쪽부터 차례로 가면 됩니다. 한 바퀴 돌 때마다 세대(Gen)가 하나 올라갑니다.

**창 바닥 상태줄이 지금 어디쯤인지 알려 줍니다.** 어느 탭을 보고 있든 같은 자리에
작가 · 조합 · 그림 · 대결 · 미확정 숫자가 있고, 그 옆 `다음` 버튼은 상태를 보고 지금 할
차례인 단계의 탭으로 데려다줍니다. **대신 눌러 주지는 않습니다** — 단계 중에 크레딧을
쓰는 것(그림 뽑기)이 섞여 있어, 앱이 알아서 소모하면 안 되기 때문입니다. 생성 진행
막대와 한 줄 설명도 여기 있습니다.

그림을 뽑은 뒤에는 사람이 직접 겨루는 **이상형 월드컵** 말고, **LLM 추천** 탭에서 로컬
VLM에게 "V4에서 쓰던 그림체와 얼마나 닮았는지"를 자동으로 점수 매기게 할 수도 있습니다.
경우의 수가 너무 많아 일일이 고르기 벅찰 때, 1차 선별을 맡기는 용도입니다 (사람 점수와는
따로 놉니다).

## 시작하기 전에

1. **로그인** — 아레나는 실제로 NovelAI에 이미지를 요청합니다.
2. **기본 프롬프트** — 메인 창에 구도·인물·품질 태그를 채워 둡니다. 아레나는 *작가 태그만*
   바꿔 가며 이 프롬프트로 그림을 뽑습니다.
3. **작가 목록** — 후보가 많을수록 조합의 폭이 넓어집니다. 10명 이상을 권합니다.

> **크레딧을 쓰는 버튼은 하나뿐입니다.** 조합을 만드는 것과 겨루게 하는 것은 공짜입니다.
> 실제로 Anlas / V5 크레딧을 소모하는 것은 조합 생성 탭의 **`그림 생성`** 하나뿐이고,
> 누르기 전에 몇 장을 뽑을지 알려 줍니다. `그림 자동 보충`도 있지만 **기본은 꺼짐**이라,
> 켜지 않으면 앱이 마음대로 크레딧을 쓰지 않습니다.

## 1. 작가 명단

조합에 뽑힐 후보이자, 그 자체로 순위표입니다. 조합이 겨룰 때마다 거기 낀 작가도 점수를
나눠 받으므로, 여러 조합에 걸쳐 꾸준히 이긴 작가가 위로 올라옵니다.

**작가를 넣는 세 가지 방법**

| 방법 | 설명 |
|---|---|
| 이름 붙여넣기 | 줄바꿈이나 쉼표로 구분해 넣습니다 |
| 프롬프트 통째로 | 가중치가 붙은 완성 프롬프트를 그대로 넣어도 **작가 태그만** 골라냅니다.<br>`1girl, 1.6::artist:kuto tubuyaki::, masterpiece` → `kuto tubuyaki` |
| 그림 끌어다 놓기 | 오른쪽 점선 과녁(또는 창 아무 데나)에 이미지를 떨어뜨리면 **그 그림에 쓰인 작가**를 뽑아 넣습니다.<br>PNG tEXt · WebP EXIF · 스텔스 메타데이터를 모두 읽습니다 |

마음에 든 그림 100장을 한꺼번에 떨어뜨려도 됩니다. 프롬프트에 `artist:`가 하나도 없는
그림은 건너뜁니다 — 그러지 않으면 `1girl`이나 `solo` 같은 평범한 태그까지 작가로
등록됩니다.

화면은 좌우로 나뉩니다 — **왼쪽이 순위표, 오른쪽이 넣는 자리**(과녁 · 붙여넣기 · `명단에
추가`)입니다.

**표에서 할 수 있는 일**

- **이름 검색** — 표 위 검색 칸으로 좁힙니다. 걸러 놓았을 때는 개수가 `N명 / 전체 M명`으로
  바뀝니다 (나머지가 지워진 것이 아니라는 뜻입니다).
- **여러 줄 골라 한 번에 삭제** — `Ctrl` · `Shift`로 고르고 `Delete` 또는 `선택 삭제`.
- **이름 직접 수정** — 칸을 눌러 바로 고칩니다. 이미 있는 이름으로는 바뀌지 않습니다.
- **`이름 다듬기`** — `mika_pikazo`를 `mika pikazo`로 일괄 정리합니다. 밑줄이 들어간
  이름이 진짜인 경우도 있어 자동으로 바꾸지는 않습니다.
- **가중치 고정** — `고정 가중치` 칸에 숫자를 넣으면 그 작가는 *항상* 그 세기로 들어갑니다.
  비워 두면 매번 새로 뽑습니다.
- **정렬** — 점수순 · 이름순 · 조합 등장순. 점수순에서는 아직 안 겨뤄 본 작가가 아래로
  갑니다 (1000점은 실력이 아니라 "모름"입니다).

`명단 비우기`는 되돌릴 수 없어 오른쪽 아래에 따로, 붉은 테두리로 떼어 놓았습니다.

작가를 명단에서 지워도 **이미 만들어진 조합과 그림, 점수는 그대로 남습니다.** 그 조합의
평가는 여전히 유효하기 때문입니다.

## 2. 조합 생성

작가를 섞어 조합을 만들고, 그 조합의 그림을 뽑습니다. 화면은 좌우로 나뉩니다 —
**왼쪽이 조작값, 오른쪽이 만들어 둔 조합**입니다. 왼쪽 세 덩어리(조합 규칙 · 뽑기 ·
기본 프롬프트)는 접혀 있고, 접힌 동안에는 현재 값을 요약 한 줄로 보여 줍니다. 머리글을
누르면 펴집니다.

| 값 | 기본값 | 뜻 |
|---|---|---|
| 작가 수 | 3 ~ 6 | 한 조합에 넣을 작가 수의 최소~최대 (1~10) |
| 가중치 방식 | 균형 | `랜덤`(균등 난수) · `균형`(상위 약 25%가 중심을 잡고 나머지가 보조) · `커브`(자리 순서에 따른 곡선) |
| 커브 모양 | 하강 | 하강 · 상승 · 역V자 · V자 · 평탄 (방식이 `커브`일 때만) |
| 가중치 최소 ~ 최대 | 0.8 ~ 1.8 | 이 범위 안에서만 뽑습니다. 최소가 최대를 넘으면 서로 밀어 줍니다 |
| 증감 폭 | 0.05 | 가중치를 이 폭의 배수로 맞춥니다 (0.01 ~ 1). `0.01`이면 1.16·1.17처럼 잘게, `1`이면 정수로 나옵니다. 최소·최대 칸의 화살표도 이 폭으로 움직입니다 |
| 넣을 위치 | 프롬프트 앞 | 작가 블록을 프롬프트 **앞** / **뒤** / `<artist>` 자리 중 어디에 넣을지 |
| 한 번에 만들 조합 | 12 | `랜덤 조합 만들기` 한 번에 만들 개수 |
| 미리 뽑아 둘 여유분 | 4 | 겨룰 그림이 이 수 아래로 내려가면 자동 보충 대상이 됩니다 (자동 보충을 켠 경우) |
| 해상도 | 메인 창 설정 | 모델이 지원하는 크기만 고를 수 있습니다. 습작이니 작게 뽑아 아껴도 됩니다 |

같은 작가 구성의 조합은 두 번 만들어지지 않습니다. 명단이 작아 더 만들 수 없으면 요청한
개수보다 적게 나옵니다.

**만들어지는 프롬프트**

| 출력 | 규칙 |
|---|---|
| `1.2::artist:a, artist:b::` | 가중치가 같은 자리는 한 블록으로 묶습니다 |
| `artist:c` | 가중치 1.0은 래퍼 없이 태그만 — 의도치 않은 강조가 섞이지 않게 |
| `1.5::artist:matrix16 ::` | 숫자로 끝나는 태그는 닫는 `::` 앞에 공백을 넣습니다. 없으면 NovelAI가 `16::`을 가중치로 잘못 읽습니다 |

`랜덤 조합 만들기`는 조합만 만듭니다. 실제로 크레딧을 쓰는 것은 **`그림 생성`** 하나뿐이라,
그 버튼만 색을 칠하고 **라벨에 몇 장을 뽑을지 적어 둡니다** (`그림 생성 (12장)`).

**미리보기**는 실제로 보낼 조건을 그대로 보여 줍니다 — 작가 조합 · 프롬프트 · 네거티브 ·
캐릭터 프롬프트. 이 넷은 모두 **메인 창의 것을 그대로** 씁니다. 매 장 달라지는 문법이
섞여 있으면 **어느 자리에 있는지까지** 알려 줍니다 (프롬프트는 멀쩡한데 캐릭터 프롬프트에
와일드카드가 있는 경우가 많습니다).

미리보기의 작가 조합은 **가장 최근에 만든 것**입니다. 규칙을 바꾼 뒤 다시 만들면 바뀐 값이
바로 보입니다. 이미 만들어 둔 조합은 그대로 남습니다 — 규칙은 새로 만드는 조합에만
적용됩니다.

**조합 큐**

만든 조합이 오른쪽 표에 최신순으로 쌓입니다. 각 줄은 **썸네일** · 상태 · 세대 · 작가
구성을 보여 줍니다. 썸네일이 비어 있으면 아직 그림을 안 뽑은 줄입니다.

- 상태 칸은 `○ 대기` · `✔ 그림 있음` · `✔ N전`으로 나뉩니다. **전적이 붙은 줄은 평가를
  담고 있다는 뜻**이니 지우기 전에 확인하세요.
- 여러 줄을 골라 `선택 삭제` 또는 `Delete`로 지웁니다 (표에 포커스가 있을 때만 듣습니다).
  그림이나 전적이 있는 조합이 섞여 있으면 먼저 묻습니다.
- `대기 중인 조합 모두 삭제`는 그림이 없는 것만 한 번에 치웁니다. 조건을 잘못 잡고 잔뜩
  만들었을 때 쓰며, **이미 그림을 뽑은 조합은 건드리지 않습니다** — 크레딧을 쓴 것들입니다.
- 생성 중에는 **지우는 것만** 막힙니다. 뽑고 있는 조합을 지우면 방금 쓴 크레딧이 갈 곳을
  잃기 때문입니다. `랜덤 조합 만들기`는 생성 중에도 눌립니다 — 만드는 것은 공짜이고,
  돌고 있는 잡은 시작할 때 뜬 목록만 보므로 새 조합이 끼어들지 않습니다.

**지운 것을 되돌리기**

`되돌리기`는 **마지막 삭제 한 번**을 되살립니다. 큐뿐 아니라 월드컵 카드의 `삭제`, 결과 탭의
`정리`로 지운 것도 같은 버튼으로 돌아옵니다. 점수·전적·세대가 모두 그대로 복구됩니다.

되돌릴 수 있는 이유는 **기본값이 그림 파일을 남기기** 때문입니다.

| `그림 파일도 휴지통으로` | 지울 때 | 되돌리면 |
|---|---|---|
| **꺼짐 (기본)** | 조합 기록만 지웁니다. 그림 파일은 폴더에 남습니다 | 그림까지 **온전히** 되살아납니다 |
| 켜짐 | 그림 파일을 **휴지통으로** 보냅니다 | 점수·전적은 살아나지만 그림은 없어 `대기`가 됩니다 |

남은 그림 파일은 어떤 조합도 가리키지 않으므로, 결과 탭의 `안 쓰는 그림 정리`로 언제든
치울 수 있습니다. 디스크가 아깝지 않다면 기본값(꺼짐) 그대로 두는 편이 안전합니다.

**그림 파일은 바로 지우지 않고 휴지통으로 보냅니다.** 크레딧을 써서 뽑은 것이라,
`되돌리기`를 놓쳤어도 Windows 휴지통에서 되찾을 수 있게 한 것입니다 (macOS는 `~/.Trash`,
Linux는 freedesktop 휴지통). 결과 탭의 `안 쓰는 그림 정리`도 같습니다. 네트워크 드라이브처럼
휴지통을 쓸 수 없는 자리에서만 바로 지우고, 그 사실을 로그에 남깁니다.

> 작가 명단에서 **가중치를 고정**해 둔 작가는 예외입니다. 고정값은 사용자가 직접 적은
> 값이라 범위와 증감 폭을 모두 무시하고 그대로 들어갑니다.

> **한 세션의 모든 조합은 같은 시드로 뽑힙니다.** 조합마다 시드가 달라지면 구도와 포즈가
> 함께 바뀌어 그림체 차이를 덮어 버리기 때문입니다. 기본 프롬프트는 메인 창의 것을 그대로
> 쓰며, 거기에 와일드카드처럼 매 장 달라지는 문법이 있으면 같은 이유로 알려 줍니다.

## 3. 이상형 월드컵

두 그림을 나란히 놓고 마음에 드는 쪽을 고릅니다. 여기가 실제로 시간을 쓰는 곳이라, 손을
마우스로 옮기지 않고 계속 고를 수 있게 만들었습니다.

| 키 | 동작 | 키 | 동작 |
|---|---|---|---|
| `←` `→` | 왼쪽 / 오른쪽 승 | `Space` | 넘기기 (점수 변화 없음) |
| `↑` | 둘 다 좋음 | `Delete` | 양쪽 삭제 |
| `↓` | 둘 다 아쉬움 | 그림 클릭 | 크게 보기 |

키는 **버튼 라벨 안에도 적혀 있습니다** (`↑ 둘 다 좋음`). 단축키를 끄면 표기도 함께
사라집니다 — 안 먹는 키를 적어 두면 거짓말이 되기 때문입니다.

이 키들은 **월드컵 탭 안이면 어디에 커서가 가 있든** 듣습니다. 방금 단추를 눌렀든 배율
슬라이더를 만졌든 상관없습니다. 다른 탭(조합 생성의 숫자 상자 등)과 메인 창에서는 원래대로
동작하니, 이 키들이 다른 화면을 방해하지는 않습니다.

`단축키 사용` 체크를 끄면 판정 키가 전부 멈추고, 방향키·`Space`·`Delete`는 슬라이더나
목록처럼 원래 받던 곳으로 돌아갑니다. 판정은 단추로만 하게 됩니다. 이 설정도 저장됩니다.

**그림을 누르면 확대됩니다 — 고르는 것이 아닙니다.** 자세히 보려고 눌렀다가 그 그림이
마음에 든 것으로 처리되면 곤란하므로, 고르는 것은 그림 아래 버튼과 방향키로만 합니다.

**화면 위쪽**

- **리그** — 겨룰 범위를 좁힙니다. `전체` · `즐겨찾기` · `미확정만`(티어가 아직 확정되지
  않은 것만).
- **배율** — 50%~250%. 고해상도 모니터에서 그림을 키워 봅니다. 배율을 올려도 창의
  최소 크기는 커지지 않으므로, 창을 작게 줄여 쓰던 중에 배율만 올려도 잘리지 않습니다.
- **그림 자동 보충** — 겨룰 그림이 떨어지면 대기 중인 조합의 그림을 자동으로 더 뽑습니다.
  크레딧을 쓰므로 **기본은 꺼짐**이고, 켜 두었더라도 **이 탭을 보고 있을 때만** 나갑니다 —
  다른 탭에서 조합을 만드는 것만으로 생성이 시작되면 곤란하기 때문입니다.
- **단축키 사용** — 위 표의 판정 키를 켜고 끕니다 (**기본 켜짐**).
- **진행 상황** — 지금 보고 있는 리그가 얼마나 확정됐는지 막대로 보여 줍니다. 전체
  숫자(작가·조합·그림·대결·미확정)는 창 바닥 상태줄에 늘 떠 있습니다.

**카드마다 있는 버튼**

선택 버튼 아래 한 줄에 다섯 개가 **전부 보입니다.** 되돌릴 수 없는 `삭제`만 오른쪽 끝으로
떼어 놓고 붉게 표시합니다. 같은 항목은 카드를 **우클릭**해도 나옵니다 (`크게 보기` 포함).

| 버튼 | 하는 일 |
|---|---|
| ★ 즐겨찾기 | 즐겨찾기 리그에 올라가고, 일괄 정리에서 제외됩니다 |
| 🔒 잠금 | 일괄 정리에서 제외되고, 전적이 없어도 교배 부모가 됩니다 |
| 가중치 리롤 | 작가는 그대로 두고 가중치만 새로 뽑습니다. **그림과 전적은 다시 시작합니다** — 가중치가 달라졌으면 사실상 다른 그림체라, 예전 전적을 물려주면 순위가 거짓말이 됩니다 |
| 복사 | 이 조합의 프롬프트를 클립보드로 |
| 삭제 | 조합을 지웁니다. 그림 파일은 기본적으로 남으며(지우도록 설정했다면 휴지통으로 갑니다), 조합 생성 탭의 `되돌리기`로 되살릴 수 있습니다 |

**겨룰 그림이 없을 때**는 왜 없는지를 넷으로 나눠 알려 주고(조합이 없다 / 그림을
기다린다 / 상대가 모자란다 / 리그를 좁혀 놓았다), 그것을 푸는 자리로 가는 버튼을 함께
줍니다.

## 4. LLM 추천 (그림체 자동 판독)

V5는 V4보다 학습량이 많아, 같은 작가·같은 가중치·같은 순서로 조합해도 V4에서 쓰던
그림체가 그대로 나오지 않습니다. 그래서 무작위 조합을 잔뜩 뽑아 놓고 **V4로 뽑아 둔
그림(참조)** 과 하나씩 대 보며 가장 닮은 것을 찾게 되는데, 경우의 수가 많아 사람이 전부
비교하기 벅찹니다. 이 탭은 그 1차 선별을 로컬 VLM(LM Studio)에게 맡깁니다.

참조 그림 여러 장을 "목표 그림체"로 등록하면, 그림이 있는 후보를 **한 장씩** VLM에 넣어
0~100 점수를 받고, 점수순으로 줄 세워 보여 줍니다. 이 점수는 이상형 월드컵의 사람 점수(Elo)와
**완전히 별개**입니다 — LLM이 추천하는 순위일 뿐이고, 최종 판단은 사람이 합니다.

> **월드컵을 대체하지 않습니다.** LLM 추천은 "이 근처부터 보라"고 후보를 좁혀 주는 도구입니다.
> 상위 몇 개를 즐겨찾기로 올려 두고, 월드컵의 `즐겨찾기` 리그에서 사람이 최종 비교하는
> 흐름을 권합니다.

### 준비물 — LM Studio와 비전 모델

이 기능은 [LM Studio](https://lmstudio.ai/)에 올린 로컬 LLM에 붙습니다. 프롬프트
어시스턴트(`Ctrl+G`)와 **같은 연결**을 씁니다.

1. **LM Studio 실행 + 로컬 서버 켜기** — 기본 주소는 `localhost:1234`입니다. 주소·타임아웃은
   **옵션 → LLM**에서 바꾸며, 이 탭은 그 값을 그대로 씁니다.
2. **비전(이미지 입력) 모델 로드** — 그림을 봐야 하므로 반드시 **VLM(Vision-Language Model)**
   이어야 합니다. 여러 참조 이미지를 한 번에 넣으므로 **다중 이미지를 지원하는 모델**
   (예: Qwen2.5-VL 계열)을 권합니다. 비전이 아닌 모델을 고르면 "이미지를 지원하지 않는
   모델"이라는 안내가 뜹니다.
3. 판독에 쓸 모델은 이 탭에서 따로 고를 수 있습니다 (프롬프트 생성용과 달라도 됩니다).

### 참조 그림체 등록

화면 위쪽 `참조 추가...`로 V4에서 뽑아 둔 이미지를 고릅니다. 여러 장을 한꺼번에 골라도
되고, 등록한 그림은 썸네일로 보입니다.

- 참조가 많을수록 "목표 그림체"가 또렷해지지만, **한 요청에 넣을 수 있는 장수에는 한계**가
  있습니다 (VLM 컨텍스트, 대략 4~6장). 상한을 넘으면 앞쪽 몇 장만 쓰고 **몇 장을 제외했는지
  알려 줍니다.** 상한은 옵션의 참조 장수 설정을 따릅니다.
- `선택 제거` · `모두 비우기`로 목록을 정리합니다. 등록한 목록은 저장되어 다음 실행에
  복원됩니다.

### 판독 실행

`판독 실행`을 누르면 **그림이 있는 모든 후보**를 순서대로 한 장씩 판독합니다.

- 후보 한 장마다 참조 그룹과 함께 VLM에 보내 0~100 점수와 짧은 근거를 받습니다. 진행
  막대와 상태줄에 `판독 중 3/12 — 점수 87`처럼 뜹니다.
- **NovelAI 크레딧을 쓰지 않습니다.** 이미 뽑아 둔 그림을 읽어 VLM에 보내는 것이라, 이
  탭은 그림을 새로 생성하지 않습니다. 그래서 메인 생성이나 조합 생성이 도는 중에도 돌릴 수
  있습니다.
- 후보가 많으면 오래 걸립니다. `중지`를 누르면 다음 후보부터 멈추고, **그때까지의 점수는
  남습니다** (한 장 판독할 때마다 바로 저장합니다).
- LM Studio에 붙지 못하거나 모델이 없으면 그 자리에서 멈추고 이유를 알려 줍니다 — 연결·모델
  로드를 확인한 뒤 다시 누르세요.

판독이 끝난 뒤 다시 실행하면 이미 점수가 있는 것도 **다시** 판독합니다 (참조를 바꿔 새로
줄 세우고 싶을 때가 있으니까요).

### 점수가 한쪽으로 몰릴 때 (모델 · 판독 지시)

판독 점수가 대부분 90점 이상에 뭉쳐 순위가 무의미해질 때가 있습니다. 원인은 두 가지입니다.

- **모델의 판별력 (주 원인)** — 그림체 유사도 채점은 VLM에게 어려운 작업이라, 판별력이
  약한 모델은 "다 비슷해 보인다 → 다 높게"로 무너집니다(점수 포화). 이럴 땐 **더 큰/좋은
  비전 모델로 바꾸는 것**이 가장 확실합니다. 실제로 작은 모델이 거의 다 95점을 준 반면,
  더 큰 모델은 점수가 고르게 퍼지고 상위 후보도 목표 그림체에 더 근접했습니다.
- **판독 지시 (부차 원인)** — 기본 프롬프트는 점수대별 기준과 "넓게 분포시켜라"는 지시로
  포화를 줄이도록 만들어졌지만, 약한 모델은 그래도 몰릴 수 있습니다.

**판독 지시 (시스템 프롬프트)** 접이식 상자에서 채점 지시를 직접 손볼 수 있습니다.

- 상자 제목을 눌러 펼칩니다. 비워 두면 내장 기본 프롬프트를 쓰고(입력칸의 안내 문구가
  이를 알려 줍니다), 무언가 쓰면 기본을 **완전히 대체**합니다.
- `기본값 넣기`를 누르면 내장 기본 프롬프트가 편집칸에 채워집니다 — 이를 바탕으로 고쳐
  쓰면 됩니다. 다시 비우면 판독 시 자동으로 기본이 쓰입니다(같은 결과).
- 모델마다 잘 듣는 지시가 다릅니다. 점수가 몰리면 "더 엄격하게, 점수를 넓게 분포시켜라",
  "대부분의 후보는 60~80에 두고 90+는 사실상 같은 작가일 때만" 같은 문구를 강조해 보세요.
- 입력한 지시는 저장되어 다음 실행에 복원됩니다.

> 판독 지시를 아무리 다듬어도 모델 자체의 변별력을 완전히 대신할 수는 없습니다. 점수가
> 계속 몰리면 지시를 손보기 전에 **비전 모델을 바꾸는 것**을 먼저 고려하세요.

### 랭킹 표와 후속 액션

화면은 좌우로 나뉩니다 — **왼쪽이 참조와 설정, 오른쪽이 랭킹**입니다. 참조 그림은 파일
고르기 말고 **끌어다 놓아서도** 넣습니다 (작가 명단 탭과 같습니다).

결과는 점수 내림차순 표로 뜹니다 — **썸네일 · 순위 · 점수 · 점수 막대 · 조합 · 근거**.
근거는 모델이 준 한 줄 설명입니다 (선 · 채색 · 색감이 참조와 어떻게 닮았는지).

점수 막대가 나란히 꽉 차 있으면 **점수가 90점대에 몰렸다는 뜻**입니다 — 숫자만 읽어서는
잘 눈에 띄지 않는데, 그때가 모델을 바꾸거나 판독 지시를 손봐야 할 때입니다
(→ [점수가 한쪽으로 몰릴 때](#점수가-한쪽으로-몰릴-때-모델--판독-지시)).

| 후속 액션 | 하는 일 |
|---|---|
| `상위 N개 즐겨찾기` | 점수 상위 N개를 **즐겨찾기**로 표시합니다. 월드컵의 `즐겨찾기` 리그로 바로 넘어가 사람이 최종 비교할 수 있습니다. 개수는 옆 상자에서 정합니다 |
| `선택 조합 복사` | 표에서 고른 조합의 작가 블록을 클립보드로 — 메인 프롬프트에 바로 붙일 수 있습니다 |
| `⋯` → `결과 저장...` | 판독 랭킹을 **CSV 파일**로 저장합니다. 스프레드시트에서 열어 기록으로 남기거나 공유하는 용도입니다. 아레나 기록 내보내기(zip)와 달리 다시 불러오지는 않습니다. 담기는 열은 아래 `판독 조건도 함께` 설정에 따릅니다 |
| `⋯` → `점수 비우기` | 모든 판독 점수와 근거를 지워 표를 비웁니다 — 참조를 바꿔 **처음부터 다시 판독**하고 싶을 때. 사람 월드컵 점수·전적·참조 이미지 목록은 그대로 두며, 되돌릴 수 없어 먼저 확인을 받습니다 |

자주 쓰지 않는 `결과 저장`·`점수 비우기`는 표 오른쪽 아래 `⋯` 메뉴에 접혀 있습니다.

### 모델을 바꿔 가며 견주기

같은 후보를 모델 A와 B로 판독해 어느 쪽이 사람 취향과 잘 맞는지 보려면, 점수만으로는
모자랍니다 — 참조를 몇 장 썼는지, 채점 지시를 손봤는지에 따라 점수가 달라지기 때문입니다.
그래서 판독할 때마다 **누가 어떤 조건으로 매겼는지**가 함께 남습니다.

- 점수마다 **그 점수를 매긴 모델 이름**이 붙습니다. 설정에 적어 둔 이름이 아니라 서버가
  **실제로 고른** 식별자입니다 — 모델 칸을 비워 두면 로드된 첫 모델이 쓰이고, 값을 적어도
  부분 일치로 골라질 수 있어서입니다. 판독이 끝나면 상태줄이 그 이름을 알려 줍니다.
- 한 회차의 조건(모델·주소·참조 장수·상한·채점 지시 수정 여부·성공/실패 수·시각)은
  `arena.json`에 함께 저장되어 앱을 껐다 켜도 남습니다.
- 왼쪽의 **`결과 저장에 판독 조건도 함께`**(기본 켜짐)를 켜 두면 CSV가 이렇게 나갑니다.

```
rank,score,model,combo,reason
1,92,qwen2.5-vl-7b-instruct,"0.9::artist:...::","선과 채색이 …"
2,71,qwen2.5-vl-7b-instruct,"0.6::artist:...::","색감은 비슷하나 …"

setting,value
model,qwen2.5-vl-7b-instruct
host,localhost:1234
timeout_seconds,120
reference_images,4
max_reference_images,5
custom_system_prompt,no
scored,18
failed,0
finished_at,2026-09-10T21:14:03
```

모델을 바꿔 다시 판독한 CSV와 **이어 붙여** 모델별로 묶어 보라고, 조건 구역이 아니라
**줄마다** 모델을 적습니다. 조건 항목 이름은 번역하지 않습니다 — 언어를 바꿔 가며 뽑은
파일이 서로 다른 열 이름을 가지면 이어 붙일 수 없기 때문입니다.

체크를 끄면 예전과 똑같은 네 칸(`rank,score,combo,reason`)만 나갑니다.

> **모델을 바꿀 때는 `점수 비우기`를 먼저 누르세요.** 비우지 않고 다시 판독하면 점수가
> 덮이지만, 실패해서 건너뛴 후보에는 앞 모델의 점수가 남아 두 모델의 결과가 한 표에
> 섞입니다. 점수를 비우면 조건 기록도 함께 지워집니다.

점수는 조합에 함께 저장되므로, 창을 닫았다 열어도 랭킹이 그대로 있습니다. **결과 탭**에서도
이 점수를 볼 수 있습니다 — 순위표에 `LLM` 칸이 뜨고, `LLM 점수순` 정렬이나 결산의
`LLM 점수 순`으로 사람 Elo 대신 이 점수를 순위에 쓸 수 있습니다
(→ [5. 결과](#5-결과-순위표--교배--결산)).

> **점수를 그대로 믿지는 마세요.** VLM의 그림체 판정은 사람과 완전히 같지 않고, 같은 후보라도
> 참조 구성이나 모델에 따라 점수가 달라집니다. "위쪽 후보부터 눈으로 확인"하는 출발점으로
> 쓰는 것이 가장 잘 맞습니다.

## 5. 결과 (순위표 · 교배 · 결산)

지금까지 알아낸 것을 한 화면에 모읍니다. 아레나를 돌리는 목적이 결국 여기 있습니다 —
마음에 든 조합을 실제 작업에 가져가는 것.

예전에는 `통계`와 `그림체 개선`이 따로 있었는데, 둘이 **같은 목록을 두 화면에서** 보고
있었습니다 (개선 탭의 "부모 후보"는 티어 시트 상위 N개와 사실상 같습니다). 그래서 마음에
드는 조합을 찾아 놓고 교배하려면 탭을 옮겨 그 조합을 다시 찾아야 했습니다. 지금은 하나로
합치고 좌우로 나눴습니다.

- **왼쪽 — 순위표 하나.** 이것이 티어 시트이자 부모 후보 목록입니다. 위에 티어·세대 분포
  막대가 붙어, 어느 쪽으로 쏠렸는지 숫자를 읽지 않고 훑을 수 있습니다.
- **오른쪽 — 고른 조합.** 그림과 프롬프트, 전적을 보여 줍니다. 그 아래로 교배 · 결산 ·
  정리 · 기록 · 작가 순위가 접혀 있고, 머리글을 누르면 펴집니다.

### 순위표

조합을 점수순으로 줄 세운 표. 세대 · 점수(Elo) · **LLM** · 전적 · 작가 구성을 봅니다.
확정되지 않은 티어에는 `?`가 붙습니다 (`S?`). `LLM` 칸은
[LLM 추천](#4-llm-추천-그림체-자동-판독) 탭에서 매긴 판독 점수이고, 아직 판독하지 않았으면
`-`입니다 — 사람 점수(Elo)와 나란히 두고 대조할 수 있습니다.

표 위의 **정렬 기준**으로 `Elo 점수순`(기본)과 `LLM 점수순`을 고릅니다. `LLM 점수순`은
**판독한 조합만** 점수 내림차순으로 보여 줍니다 (판독 안 한 것은 순위 오해를 막으려
빠집니다). `Elo 점수순`은 판독 여부와 무관하게 전부 올립니다.

줄을 고르면 오른쪽에 그 조합의 **그림과 프롬프트**가 뜹니다. `메인 프롬프트로 보내기`를
누르면 메인 창 프롬프트 앞에 붙고, `복사`는 클립보드로 보냅니다.

`작가 순위`(접이식)는 상위 20명을 보여 줍니다 — 조합이 아니라 **작가 단위**로 취향을
알려 줍니다. 작가 명단 탭의 표와 같은 내용이니, 전체를 보려면 그쪽이 낫습니다.

### 교배

점수가 매겨진 상위 조합을 부모로 삼아 자식을 냅니다. 부모 후보는 **썸네일과 함께**
보여 줍니다 — 태그 문자열만 보고 고르라는 것은 불친절하니까요.

| 값 | 기본값 | 뜻 |
|---|---|---|
| 만들 자식 수 | 8 | 한 번에 만들 자식 조합 수 |
| 부모로 쓸 상위 조합 | 20 | 점수 상위 몇 개까지를 부모 후보로 볼지 |
| 돌연변이율 | 0.15 | 자식의 자리 하나가 명단의 다른 작가로 바뀔 확률 |
| 가중치 흔들기 | 0.15 | 물려받은 가중치를 위아래로 흔드는 폭 |

자식은 작가 구성뿐 아니라 **가중치도 물려받습니다.** 매 세대 가중치를 새로 뽑으면
"이 작가를 세게 쓴 게 좋았다"는 정보가 사라지기 때문입니다. 점수는 부모 평균에서 시작하고,
전적이 없으므로 몇 판이면 제자리를 찾습니다.

부모 후보는 **전적이 있거나 잠근 조합**입니다. 둘이 안 되면 버튼이 눌리지 않고, **무엇이
모자란지 버튼 아래에 적어 둡니다.** 만든 자식은 그림이 없으므로, 조합 생성 탭으로 돌아가
`그림 생성`을 눌러야 겨룰 수 있습니다.

### 정리

**정리(물갈이)** 는 `최소 대결 수`만큼 싸웠는데 `점수 기준`보다 낮은 조합을 한 번에 치웁니다
(기본: 5전 이상 · 960점 미만). 취향이 아닌 작가를 알게 됐다면 `이 작가가 낀 조합 지우기`로
관련 조합을 통째로 지울 수 있습니다.

> 한 번에 여러 개가 사라지므로 지우기 전에 대상 개수를 보여 주고 확인을 받습니다.
> 즐겨찾기와 잠근 조합은 조건에 맞아도 남고, 잘못 눌렀으면 조합 생성 탭의 `되돌리기`로
> 되살릴 수 있습니다.

### 초기화

| 버튼 | 지우는 것 | 남는 것 |
|---|---|---|
| 대전 기록 초기화 | 점수와 전적만 | 작가 명단 · **조합** · 그림 |
| 통계 초기화 | 점수 · 전적 · **조합 목록** · 티어 시트 · 세대 분포 | 작가 명단 |
| 안 쓰는 그림 정리 | 어떤 조합도 가리키지 않는 그림 파일 (휴지통으로) | — |

`대전 기록 초기화`는 조합을 남기고 점수만 0으로 돌립니다 — 같은 조합으로 순위를 다시 매기고
싶을 때 씁니다. 그래서 세대 분포와 티어 시트에는 줄이 그대로 남습니다. 표까지 비우려면
**`통계 초기화`**를 쓰세요.

`통계 초기화`를 누르면 무엇이 지워지고 무엇이 남는지 개수와 함께 보여 주고, **`기록
내보내기`로 먼저 백업하라고** 안내합니다. 실수로 눌렀어도 조합 생성 탭의 `되돌리기`로
되살아나지만(그림 파일도 기본값에서는 남습니다), 다른 삭제를 한 번 더 하면 그 기회는
사라집니다.

셋 다 **작가 명단은 남깁니다.** 점수만 새로 매기고 싶은데 애써 모은 후보까지 날아가면
곤란하기 때문입니다. 명단을 비우려면 작가 명단 탭의 `전체 삭제`를 쓰세요.

### 결산 — 순위대로 실제 그림 뽑기

순위가 나왔으면 위에서부터 차례로 그림을 뽑아 한 벌로 보고 싶어집니다. 조합을 하나씩 골라
프롬프트에 붙이는 대신, 순위대로 큐를 만들어 한 번에 돌립니다.

| 항목 | 뜻 |
|---|---|
| `상위 N` | 순위 위에서부터 몇 개까지 올릴지 (1~200) |
| `조합당 M` | 조합 하나마다 몇 장을 뽑을지 (1~20) |
| `전적 없는 조합도` | 한 번도 안 싸운 조합까지 포함할지. **기본 꺼짐** |
| `LLM 점수 순` | 사람 Elo 대신 [LLM 추천](#4-llm-추천-그림체-자동-판독) 판독 점수로 순위를 매깁니다. 켜면 **판독한 조합만** 점수순으로 뽑히므로, 월드컵을 안 돌렸어도 LLM 추천 순서 그대로 결산할 수 있습니다. 이때 `전적 없는 조합도`는 뜻이 없어 비활성화됩니다. **기본 꺼짐** |
| `결산 생성` | 큐를 만들어 생성을 시작합니다 |

- 1등을 M장 다 뽑고 2등으로 넘어갑니다 — 결과 폴더에 **등수 순서 그대로** 쌓입니다.
- 버튼 아래에 `대상 조합 N개 · 뽑을 그림 M장`이 늘 떠 있고, 누르면 한 번 더 확인합니다.
  크레딧을 쓰는 동작이기 때문입니다.
- **결과는 결과 폴더에 저장됩니다** — 아레나 폴더의 습작과 다른 자리입니다. 갤러리·결과
  미리보기·파일명 규칙·메타데이터까지 평소 생성과 똑같습니다.
- 프롬프트·모델·해상도·스텝은 **메인 창의 지금 설정**을 그대로 씁니다. 작가 블록만 조합마다
  갈아 끼웁니다 (넣을 위치는 조합 생성 탭의 설정을 따릅니다).
- 시드도 메인 창의 `시드 랜덤` 설정을 따릅니다. **꺼 두면 같은 시드로 그림체만** 바뀐 한 벌이
  나오고, 켜 두면 장마다 다른 그림이 나옵니다.
- 전적이 없는 조합을 기본으로 빼는 이유는, 1000점이 실력이 아니라 '모름'이기 때문입니다.
  결산에 섞이면 순위가 있는 것처럼 보입니다.
- 메인 생성이 도는 중에는 시작하지 않습니다 (반대도 마찬가지입니다).

### 기록 내보내기 · 불러오기

아레나 폴더는 하나뿐입니다. 다른 주제로 새로 시작하려면 지금까지 쌓은 점수와 그림을
덮어써야 했는데, 한 벌을 통째로 담아 두었다가 나중에 그대로 되살릴 수 있습니다.

| 버튼 | 하는 일 |
|---|---|
| `기록 내보내기...` | 작가 명단 · 조합 · 점수 · 전적과 **그림 파일까지 zip 하나**에 담습니다. 아레나 폴더는 그대로 둡니다 |
| `기록 불러오기...` | 담아 둔 zip을 읽어 **지금 기록을 갈아 끼웁니다.** 그림도 함께 돌아옵니다 |

- 파일 이름은 `arena-20260908-1430.zip`처럼 날짜를 붙여 제안합니다. 여러 벌을 모아 둬도
  언제 것인지 보입니다.
- zip 안은 `arena.json` + `images/`입니다. 폴더로 풀고 싶으면 탐색기에서 그냥 풀면 되고,
  풀어 둔 폴더를 다시 zip으로 묶어도 그대로 읽힙니다.
- **불러오면 지금 기록이 사라집니다.** 무엇이 사라지고 무엇이 들어오는지 개수를 보여 주고
  확인을 받습니다. `되돌리기`로는 복구되지 않으니, 지금 것을 남기려면 **먼저 내보내세요.**
- 생성이 도는 중에는 불러오지 않습니다 — 뽑던 그림이 갈아 끼우기 전 조합의 것이기 때문입니다.

> 남이 만든 zip이라도 아레나 폴더 밖에는 아무것도 쓰지 않습니다. 경로가 폴더를 벗어나는
> 항목과 이미지가 아닌 파일은 버립니다.

## 점수는 어떻게 매겨지나

체스에서 쓰는 Elo 레이팅을 그대로 씁니다. 이기면 오르고 지면 내려가되, **강한 상대를
이겼을 때 더 많이 오릅니다.** 모든 조합은 1000점에서 시작합니다.

**K값 — 한 판이 점수를 얼마나 흔드는가**

| 치른 판수 | K | 뜻 |
|---|---|---|
| 0 ~ 4전 | 32 | 크게 움직여 빨리 제자리를 찾습니다 |
| 5 ~ 9전 | 24 | 점차 안정됩니다 |
| 10전 이상 | 16 | 잘 흔들리지 않습니다 → **티어 확정** |

10전을 채우면 티어가 확정됩니다. 그 전까지는 결과 탭에서 `?`가 붙어, 두 판 싸운 1300점을
확정된 S로 오해하지 않게 합니다.

**티어 경계**

| 티어 | 점수 | 대략의 뜻 |
|---|---|---|
| S | 1200 이상 | 취향에 가장 가까운 조합 |
| A | 1120 ~ 1199 | 교배 부모로 쓰기 좋은 구간 |
| B | 1040 ~ 1119 | 평균 위 |
| C | 960 ~ 1039 | 평균 근처 (시작점은 1000점) |
| D | 880 ~ 959 | 정리 대상 기본 구간 |
| F | 880 미만 | 취향이 아닌 쪽 |

**대진**은 무작위가 아닙니다. 가장 덜 싸운 조합을 먼저 올리고, 그 상대는 점수가 가까운 후보
중에서 역시 덜 싸운 쪽을 고릅니다. 승부가 뻔한 대결이 줄어 같은 클릭 수로 순위가 더
정확해집니다. 직전과 같은 짝이 연달아 나오지도 않습니다.

**작가 점수**는 조합의 점수 변화량을 **자리 가중치에 비례해** 나눠 받습니다.
`1.5::artist:a::`와 `0.5::artist:b::`로 이뤄진 조합이 20점을 얻었다면 `a`가 15점, `b`가
5점을 받습니다 — 세게 들어간 작가가 결과에 더 책임이 있으니까요.

## 파일이 저장되는 곳

아레나 데이터는 일반 결과물과 **따로** 둡니다. 아레나가 뽑는 그림은 습작이라, 결과 폴더에
섞이면 갤러리가 습작으로 뒤덮입니다.

| 경로 | 내용 |
|---|---|
| `artist_arena/arena.json` | 작가 명단 · 조합 · 점수 · 세대 |
| `artist_arena/images/` | 조합마다 뽑은 그림 |

기본 위치는 앱 데이터 폴더 아래이고, **옵션 → 폴더 경로**에서 바꿀 수 있습니다.
**폴더 메뉴 → 그림체 아레나 폴더**로 탐색기에서 바로 엽니다. 그림은 한 장 뽑을 때마다 곧바로
기록되므로, 도중에 앱이 꺼져도 이미 쓴 크레딧이 날아가지 않습니다.

| `그림 생성`을 눌러도 시작되지 않는다 | 메인 창에서 생성이 돌고 있으면 아레나가 시작되지 않습니다 (반대도 같습니다). NovelAI는 계정당 요청을 하나씩 보내는 것이 규칙이라 순서를 지킵니다 |
| 가중치 범위를 바꿨는데 옛 값이 보인다 | 규칙은 **새로 만드는 조합**에만 적용됩니다. `랜덤 조합 만들기`를 다시 누르면 미리보기에 새 값이 뜹니다. 작가 명단에서 가중치를 고정해 둔 작가는 범위를 무시합니다 |
| 조합을 만들었는데 개수가 모자라다 | 작가 명단이 작아 더 만들 조합이 없는 경우입니다. 같은 작가 구성은 두 번 만들지 않습니다 — 작가를 더 넣으세요 |
| 교배 버튼이 눌리지 않는다 | 전적이 있거나 잠근 조합이 **2개 이상** 있어야 합니다 (버튼 아래에 그렇게 적혀 있습니다). 월드컵을 몇 판 돌린 뒤 다시 오세요 |
| 티어가 계속 `?`다 | 그 조합이 아직 10전을 채우지 못했습니다. 창 바닥 상태줄의 `미확정` 숫자가 몇 개 남았는지 알려 줍니다. 리그를 `미확정만`으로 두면 그 조합들이 먼저 올라옵니다 |
| 그림마다 배경·포즈가 다르다 | 기본 프롬프트에 와일드카드나 `<a\|b>` 같은 문법이 있습니다. 조합 생성 탭에 경고가 떠 있을 겁니다 — 빼고 다시 뽑으세요 |
| 아레나 창의 윗부분이 잘린다 | 창 바닥의 `창 크기 초기화`를 누르세요. 기본 크기로 화면 가운데에 놓고 배율도 100%로 되돌립니다 |
| 창이 좁아 좌우 어느 한쪽만 보인다 | 좌우를 가르는 선을 끌어 비율을 바꾸거나, 한쪽 끝까지 밀어 접으세요. 창을 넓히면 저절로 나뉩니다 |
| 지웠는데 폴더에 그림이 남는다 | 기본 동작입니다 — 되돌릴 수 있게 파일을 남깁니다. 결과 탭의 `안 쓰는 그림 정리`로 치우거나, 조합 생성 탭의 `그림 파일도 휴지통으로`를 켜세요 |
| 실수로 조합을 지웠다 | 조합 생성 탭의 `되돌리기`를 누르세요. 마지막 삭제 한 번을 되살립니다 (월드컵·결과 탭에서 지운 것도 포함) |
| 그림 파일까지 지워 버렸다 | **휴지통을 확인하세요.** 아레나는 그림을 바로 지우지 않고 휴지통으로 보냅니다. 되살린 뒤 아레나 폴더의 `images/`에 같은 이름으로 돌려놓으면 조합이 다시 그림을 찾습니다 |
| LLM 추천의 `판독 실행`이 눌리지 않는다 | 참조 그림을 하나 이상 등록하고, 그림이 있는 후보가 하나 이상 있어야 합니다. 조합 생성 탭에서 `그림 생성`을 먼저 누르세요 |
| 판독이 "연결" 오류로 멈춘다 | LM Studio가 실행 중이고 **로컬 서버가 켜져** 있는지, 옵션 → LLM의 주소(`localhost:1234`)가 맞는지 확인하세요. 프롬프트 어시스턴트(`Ctrl+G`)의 연결 테스트로도 확인할 수 있습니다 |
| 판독이 "이미지를 지원하지 않는 모델" 오류를 낸다 | 고른 모델이 비전(VLM)이 아닙니다. LM Studio에서 이미지 입력이 되는 모델(예: Qwen2.5-VL)을 로드해 고르세요 |
| 참조를 여러 장 넣었는데 일부만 쓴다 | 한 요청에 넣을 수 있는 장수 한계 때문입니다. 상한을 넘으면 앞쪽 몇 장만 쓰고 제외 장수를 알려 줍니다. 옵션의 참조 장수 상한을 조정하거나, 대표 이미지 위주로 줄이세요 |
| 점수가 실제 그림체와 안 맞는 것 같다 | VLM 판정은 사람과 완전히 같지 않습니다. LLM 추천은 후보를 좁히는 1차 선별로 쓰고, 상위 후보는 이상형 월드컵에서 눈으로 최종 확인하세요 |
| 점수가 대부분 90점 이상에 몰린다 | 주로 모델의 판별력 문제입니다 — 더 큰/좋은 비전 모델로 바꿔 보세요. 그다음으로 `판독 지시 (시스템 프롬프트)`를 펼쳐 "더 엄격하게, 넓게 분포"를 강조하도록 채점 기준을 손보세요 ([점수가 한쪽으로 몰릴 때](#점수가-한쪽으로-몰릴-때-모델--판독-지시)) |
| 참조를 바꿔 다시 판독하고 싶다 | `⋯` 메뉴의 `점수 비우기`로 판독 점수를 지운 뒤 참조를 바꿔 `판독 실행`을 다시 누르세요. 사람 월드컵 점수·전적은 그대로 남습니다 |
| 판독 결과를 따로 남기고 싶다 | `⋯` 메뉴의 `결과 저장...`으로 랭킹을 CSV 파일로 내보냅니다. 엑셀·스프레드시트에서 바로 열립니다 (한글도 깨지지 않게 저장합니다) |

## 생성 진행 상황

창 바닥 **상태줄**에 진행 막대와 한 줄 설명이 뜹니다. 탭 밖에 있어서 월드컵이나 결과를
보고 있어도 어디까지 갔는지 보입니다.

| 표시 | 뜻 |
|---|---|
| `N장 생성을 시작합니다 (시드 …)` | 큐에 넣은 장수와 이번 세션의 시드 |
| `생성 중 3/12 — 1.2::artist:…` | 지금 뽑고 있는 조합 |
| `완료 3/12 — 남은 9장` | 방금 한 장이 저장됐습니다 |
| `재시도 대기 3/12 — … (5초 후, 1번째)` | 일시적 오류로 같은 장을 다시 시도합니다 |
| `다음 장(4/12)까지 3초 대기` | 요청 간 간격을 지키는 중입니다 |

`중지`를 누르면 다음 장부터 멈춥니다. 이미 뽑은 그림은 그대로 남습니다.

## 알아 두면 좋은 것

- 화면에서 만진 값은 전부 설정에 남아 다음 실행에 복원됩니다.
- 아레나 생성은 **메인 생성과 같은 줄에 섭니다.** 메인 배치가 도는 중에는 아레나가 시작되지
  않고, 반대도 마찬가지입니다.
- 창을 닫아도 진행 중인 생성은 멈추지 않습니다 (멈추려면 `중지`를 누릅니다).
- 아레나가 뽑은 그림은 갤러리·결과 미리보기에 끼어들지 않습니다.
- 창은 **최소화·최대화**할 수 있습니다 — 그림을 크게 놓고 고를 때 씁니다
  (→ [곁창 다루기](../MANUAL_KR.md#곁창-다루기-최소화--최대화)).
